# Multilevel Projects using NGSolve

Projects implementing multilevel methods on finite element problems. Born out of a project for a data science course with Dr. Panayot Vassilevski. 

## Purpose and Roadmap

The project is currently focused on implementing Gauss Seidel and multilevel methods as preconditioners for Preconditioned Conjugate Gradient.  Future plans include applying the method to various PDE problems and incorporating Monte Carlo Methods.

## Language

Python interface, NGSolve also utilizes C++.

## NGSolve Rights

NGSolve is not ours.  For questions about it please go to NGSolve.org.  We are just using the open resource.
