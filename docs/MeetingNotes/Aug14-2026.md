### Generic MC solver initial sketch

```
MC Wrapper:
outside function that says calc QOI, run trials, are we close enough, run more, then stop when QOI in target  

Input: stopping condition based on QOI, 
Output: number of runs, solutions from all the runs

Algorithm:
    determine how many correlated runs to do
    run correlated trials
    keep running single trials until stopping condition met
    return number of trials used and solution set
```

```
Trial Maker:
Inputs: function to make one iteration of random matrix, solving function
Output: one x for each trial
stuff it does inside:
    one trial:
        call random matrix generator for that problem
        solve in some way that returned matrix
        return the solution
```

```
Two levels of coordinated trials:
Inputs: a function that makes two levels of coordinated random matrices, solver function
Returns: two trials with correlated randomness for difference part of MC
```

```
Function for making matrices (graph laplacians) with random coefficients  
*always has to be type of problem specific*
generate random coefficients in here
I give you CSR matrix with those in it for solving
```

```
Function for making two correlated random matrices:
*problem specific*
make two levels of correlated matrices with matching random coefficients
return the two matrices
```

```
Function to calc QOI
given a single x solution, calculate problem specific QOI, return that #
```

```
Solver:  
given matrix and RHS, solve (could be direct or multilevel or whatever)
```
