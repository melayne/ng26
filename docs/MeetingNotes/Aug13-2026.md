### Algorithm steps

0. Import data  
    a. Turn .mtx or an edge-list into expected edge-list format  
    b. $n = $ number of vertices (nodes)  
    c. $edges = $ list of edges ($e =$ the number of edges)  
    d. $weighted = \{1,0\}$ if the graph is weighted or unweighted
1. Make $A, D, L \in \mathbb{R}^{n\times n}$, and $B \in \mathbb{R}^{n\times e}$ from graph data.  
    a. $A = $ adjacency matrix, $a_{ij}=1$ if there is an edge between node $i$ and node $j$  
    b. $D = $ degree matrix, diagonal with $d_{ii}=c$ where $c$ is the number of edges connected to node $i$  
    c. $L = $ graph Laplacian matrix, $L = D - A$  
    d. $B = $ vertex - edge incidence matrix $b_{ik} = 1$ if vertex $i$ is connected to edge $k$
2. Make shifted Laplacian ($L$ is singular, need SPD for Cholesky)  
    a. Build $D^{-1}L$  
    b. Call scipy eigs to get the first $k$ eigenvalues ($k$ just needs to be large enough to get the positive eigenvalues)  
    c. Find $\lambda_{min}^+$ the smallest positive eigenvalue  
    d. Choose a $\sigma^2$, currently using $\sigma^2 = 0.25$  
    e. Assemble the matrix $L_{\sigma} = L + \sigma^2 \lambda_{min}^+ D$  
    f. Calculate the Cholesky decomposition of $L_{\sigma} = C C^T$
3. White noise pipeline  
    a. Create edge weight vector of length $e$ by sampling from random Normal distribution $\mathbf{w} = [w_1, w_2, \ldots, w_e]$, such that $w_i \sim N(0,1)$  
    b. For each node, its random weight is the sum of the weights of the edges that touch it $f_e = \sum w_e$, calculate this for all nodes by $\mathbf{f} = B \mathbf{w}$  
    c. To correlate the node weights spatially, solve the following for $u$,  
    $$
    L_{\sigma}u = \sqrt{\lambda_{min}^+} f
    $$  
    using the Cholesky decomposition we made earlier  
4. Make the node weights 
    $$
    k_e = \exp\left( \frac{u_i + u_j}{2}\right)
    $$  
5. Solve for Darcy flow  
    a. Build the weighted graph Laplacian
    $$
    L_k = D_k - A_k
    $$  
    b. Build the right hand side
    $$
    b = L_k [interior][boundary]@ pressure
    $$
    c. Solve for $p$
    $$
    L_k p = b
    $$
6. Find the quantity of interest
$$
Q = k_e \lvert p_i - p_j \rvert
$$
7.  MC Loop is steps 3-6
